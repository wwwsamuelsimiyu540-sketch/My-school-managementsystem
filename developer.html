Security Settings

Review the security requirements for the platform.

  • Enable Row Level Security on protected tables.
  • Restrict school approval and suspension to authorized developers.
  • Use Supabase Auth to identify signed-in users.
  • Never expose a service-role or secret key in browser code.
  • Protect each school's records from other schools.

This page provides security guidance; it does not automatically change database policies.
